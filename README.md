# Lumen Commerce

Full demo ecommerce store with storefront + admin.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

**Admin:** `/admin` — `admin@lumen.store` / `admin123`

## Included

- Product catalog, cart, checkout
- Admin: products, orders, customers, settings
- Payment gateways: Stripe, PayPal, Razorpay, Cash on Delivery (test/sandbox)
- Shipping: free, flat, UPS / FedEx / DHL quote calculators
- Inventory deduction on purchase
